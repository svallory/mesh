# create-mesh

**Mesh is coming soon.**

Mesh is a TypeScript framework for Bun: one entity file declares your data, actions and rules, and
Mesh derives the types, handlers, database schema, API, client and agent tools from it.

This package is the starter. When Mesh ships, this creates a project:

```sh
bun create mesh todo-app
```

Until then it prints a pointer to the site. Read about Mesh, its syntax and its roadmap at
**https://mesh.hyperlab.sh**.
