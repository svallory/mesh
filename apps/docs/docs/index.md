# Mesh

Mesh is a planned TypeScript framework modelled on [Ash](https://ash-hq.org), the declarative resource framework for Elixir. You describe a resource once, in one `.mx` file: its data, its actions and its rules. Mesh derives types, handlers and schema from that file. Mesh runs on Bun only.

::: callout warning "Pre-release"
Mesh does not have a release yet. There is nothing to install and no runtime. The pages under **Docs** describe only what exists today.
:::

Mesh is open source under the MIT licence.
