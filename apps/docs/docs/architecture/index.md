# Architecture

This section is for people who work on Mesh.

::: callout info "The rule"
**Document here everything that cannot be understood by looking at a single code file.**

If a reader can learn it by opening one file, put it in that file as a comment or type. If it spans files, records a choice, or explains why, it belongs here.
:::
